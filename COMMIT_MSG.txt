objunpack: check-quarantine deletes its extracts once a package is sent

The FTPS step of _TEMPLATE-objunpack-check-quarantine.xml now carries
deleteOnSuccess=${dir.PRECHECK}/${runId}/${packageNoString}: once a
package has been sent as it is, the audit and metadata the Look inside
step extracted from it are deleted. A package put in the quarantine list
keeps its folder, with the validation report that says which line and
column failed. The author's change, made by hand on the server, extended
from the metadata file to the whole per-package folder.

The run folder is deliberately not used: on the FTPS step it would
delete, at every send, the folders of the packages listed before it.

USAGE and spec section 24 (U38, U39). No script and no Java change.
