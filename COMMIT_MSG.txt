objunpack: specification and Gate 0 (batch 0, docs only)

.claude/OBJECT_UNPACK_EXECUTOR.md specifies objunpack, the inverse of
objpack: a Transarch object package (.tar or .tar.gz, plus .md5) back
to its metadata CSV and its objects under their original names, for
the chain csvsql -> dequote -> validate -> objpack -> ftpsend.

No code. Batches 1-4 wait for the eight Gate 0 answers in section 11.

The name mapping is the join audit.json (file_name, object_id) with
metadata.csv (object_id, original_object_name), never a name template.
Section 3 records what that decision met on ten packages made by the
real producers, objpack and the legacy PowerShell script:

- AuditJson has no reader and SubmissionName parses no names: both are
  specified as additions to those classes, objpack's writing untouched.
- The legacy tar holds the objects BEFORE audit and metadata: objects
  are staged under their member names and renamed afterwards.
- PsCsvReader reads the packaged metadata; FlatCsvReader miscounts a
  record that spans two lines.
- LinkGuard is not called: a package is flat, a link is refused.
- A full package has 100 003 members, above unarchive's maxEntries.
- objpack's default delimiter would change a legacy feed's; the
  template passes the package's own.

Eight intersections decided by name (U1-U8); seven limits declared.

Found, NOT fixed here: ObjectPack.glob lower-cases a regex built with
Pattern.quote, so any include/exclude pattern other than bare * or ?
throws when the objects directory is listed. Needs its own patch.

Verified on Linux (sandbox; Temurin 1.8.0_432 run, PowerShell 7.4.6,
GNU tar 1.35, bsdtar 3.7.2, root, LANG=C.UTF-8): the reused packages
compiled with the Java 8 javac; ten real packages; the tar readers
against Python tarfile; both CSV readers against Python csv; a
prototype of the join re-packed by the real ObjectPack, 9 of 10 both
for restore and round trip, the exceptions being declared limits;
git apply --check on a second clean clone.
Verified on Windows: nothing.
Not verified on either: any implementation of objunpack (none
exists); Windows PowerShell 5.1; a legacy package made on Windows; the
chain's csvsql, dequote, validate and ftpsend on an unpacked CSV.
