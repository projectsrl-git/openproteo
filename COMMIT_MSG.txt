objunpack: add the loop-only and two-workflow templates as alternatives

The two shapes delivered before the one-workflow template, and not
committed, are added unchanged on the current scripts:

- _TEMPLATE-objunpack-precheck-resend-all.xml: one loop over a folder,
  no list; the first package that cannot be worked stops the run.
- _TEMPLATE-objunpack-check-quarantine.xml and
  _TEMPLATE-objunpack-correct-quarantined.xml: check and quarantine list
  in one workflow, correction of the list in another, resumable.

USAGE gains "The same work in other shapes" (the one-workflow template
stays the recommended one; the pair keeps its list in the shared files,
so each copy of the pair needs a list name of its own). Spec section 23
(U35-U37). No script and no Java change.
