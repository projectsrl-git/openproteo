Clean: no default-charset read or write of file content; every output

Findings that change what a feed does on Linux:
- File.renameTo replaces an existing <name>.done on Linux and refuses
  on Windows (elarxml, json2csv, ftpsend, elar split).
- "*.csv" matches DATA.CSV on Windows and not on Linux, exit 0
  (filecopy, safecopy).
- ${matchedFiles} is in name order on NTFS and hash order on Linux, and
  a forEach iterates it (filecopy, safecopy, encoding batch).
Plus: backslash in a path parameter, two recursive deletes that follow
links, tiffcompress report order, the FTPS trust default.
