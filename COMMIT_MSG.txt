feed schema index: variable columns are resolved, tokens survive

Gate 0 answered on the one question that changes what a column means:
the workflow variables asked for by name are emitted RESOLVED, not as
the raw declaration the spec recommended. Spec only, no code.

Resolution runs against the map Operations already uses for feed tags -
file globals, feedId/parentId/sourceId/targetId, and the workflow's own
<variables> - innermost-first as VarResolver does it, so a variable
built out of another one resolves for real and the index cannot
disagree with the Operations grid about the same feed.

One deliberate divergence from VarResolver, and it is what makes
resolving safe here. VarResolver gives an unknown name the empty
string, which is right at runtime and wrong at design time: ${runDate}
and ${extract.rowCount} do not exist yet, so an empty cell would be
indistinguishable from "this feed does not define the variable". An
unresolvable token therefore stays the literal ${name}. A cell either
carries a value that is true at design time or visible evidence that it
is computed at run time, and can never be a lie; variables_unresolved
counts the occurrences. ${list[N]} and ${COL@key} stay literal too -
they only mean something against a run's published lists.

The recommendation that was overruled is left standing in the spec
rather than deleted. The token rule exists to close the same failure
the raw recommendation was arguing about, and it only reads as a
decision beside what it replaced.

Two costs are recorded rather than absorbed. This is a third
implementation of ${} resolution after VarResolver and the Operations
tag map, contained by scope and by a suite that lifts VarResolver's
patterns out of the Java at build time and asserts agreement, as the
displayschema aliases already will. And global variables become an
input: without a readable orchestrator.global-vars every ${someGlobal}
degrades to a token, so -GlobalVarsFile names the file and the summary
reports how many were loaded, saying 0 explicitly rather than staying
silent.
