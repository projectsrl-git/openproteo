objunpack: a sent list, so that no run sends a package twice

New scripts/sent-list.sh records, after every successful send, the
package's name - and, for a rebuilt package, the version + 1 it was sent
as. list-packages.sh gets an optional skipList parameter that leaves out
every package whose name is in that list (new variables skippedCount and
skippedNames); without it nothing changes.

The four templates that send (check-quarantine, correct-quarantined,
check-and-correct, precheck-resend-all) now carry sentList, pass it as
skipList to List packages, and record each send right after its FTPS
step. A package left in the folder is no longer sent again by the next
run, also after it was corrected and sent as V002. To send one again,
delete its line. The pair shares one list in the shared files.

USAGE: a range of packages with shell character classes (S100-S187),
the sent list, the transition limit (eleven per package now, about 45 a
run) and how to raise it at start-up. Spec section 25 (U40-U46).

Verified on Linux (JDK): Temurin 1.8.0_432 and JDK 21.0.12; scripts and
templates walked, mutations; also as a non-root user.
Verified on Windows: nothing (bash scripts).
Not verified: a real FTPS send, the engine itself, AIX.
