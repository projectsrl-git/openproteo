AIX gets the POSIX name rules; nameRules on the objunpack step

On an AIX server objunpack stopped with "this host is neither Windows
nor Linux (os.name='AIX')". By the author's decision AIX is treated as
Linux, and the choice of rules is settable from the GUI.

- HostRules.detect returns the Linux (POSIX) rules for AIX. unarchive
  shares the class and now runs on AIX too. The first log line says
  "file-name rules: linux (os.name AIX, a POSIX system)".
- New step parameter nameRules on objunpack: auto (default), linux or
  windows - for a server the detection does not know. In the panel's
  Output section, seeded with the other defaults, applied at the next
  run of the step, no restart. windows may be chosen anywhere; linux
  on a Windows server is refused, because Windows would not store
  those names as written.
- With maxPathLength=auto objunpack uses 1023 bytes on AIX (its
  PATH_MAX, from the documentation) instead of 4096.

No file-only key (checklist 10). On Windows and Linux nothing changes.
USAGE.md updated for both executors; the template carries
nameRules=auto. README.md and CLAUDE.md not touched.
