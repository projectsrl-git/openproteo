objunpack: check every package, then send the valid ones in one block

New template _TEMPLATE-objunpack-check-then-send.xml, no Java. A loop
that only checks: each valid package is PREPARED - a folder in a
staging folder with a link to the package and one to its .md5, the
packages' folder never written - and the others go to the quarantine
list as before. Then one ftpsend with forEach, concurrency 1: one FTPS
session per package, the package then its .md5, each link renamed
.sent once its file is sent and verified. sent-list.sh action=reconcile,
at the end and at the start of the next run, records every package
whose two files were sent; a package sent in part gets its .md5 alone;
what was prepared and not sent is sent by the next run without being
checked again (Fabiano's answers a-d, 2026-10-14).

- scripts/send-stage.sh (new): verdict send/correct/manual, the links,
  the extracts handed to deleteOnSuccess only when prepared; a staging
  folder in or under the packages' folder refused before anything is
  created, on physical paths.
- scripts/sent-list.sh: action reconcile; one function writes a line
  for add and reconcile; add unchanged.
- check-quarantine and every other template unchanged.
- Spec OBJECT_UNPACK_EXECUTOR.md section 26, intersections U47-U57;
  USAGE subsection; session note.

With no hold, that variable is the only thing between a copy of the

Read in the code and different from what was expected: forEach splits
on commas too without delimiter (the step sets ";"); forEach runs no
deleteOnSuccess and drops the items' outputs; after a failure it tries
the remaining packages (server down: each waits the connect timeout).

Verified on Linux (JDK Temurin 1.8.0_432 and OpenJDK 21.0.12): scripts
57 assertions + 8 permission cases, root and uid 65534, LANG empty and
C.UTF-8; template walked, 484 assertions (parser, VarResolver, bash
runner, runFtpSend and deleteOnSuccess real; node loop, fan-out,
validate and FTPS server mine), FTP stopped at every position in three
ways and resumed: each file once, never an .md5 before its package,
each name once in the sent list; 45 mutations, 44 caught, 1
equivalent, 1 suite hole closed. 900 packages: reconcile 4 s / 9 s.
Verified on Windows: nothing (the template needs bash and links).
Not verified: the engine itself, concurrency other than 1, a real
FTPS server, Transarch on a half-sent package (questions in the note),
AIX.
