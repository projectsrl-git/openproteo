Command-line control

The command line (openproteo-headless.war cli) drives this instance through a control directory on this server: it starts, stops and approves runs, and reads their status and logs, without a page and without HTTP. Whoever may create files in its inbox folder may do all of that, and is recorded in the audit under their own Windows or Linux account. The folder is not created here: create it with inbox and outbox inside and the permissions described in the documentation. Here you also choose the address these pages answer on (standalone only): with 127.0.0.1 they can be opened only from a session on this server. A saved value applies at the next start.

Diagnostic snapshots

A snapshot is a text file that says what the engine is doing, how busy the Java runtime and the host are, how fast the disk answers, and where every thread is. One is taken automatically when a run is RUNNING with no step running and does not move for 2 minutes — stuck between two steps — and you can take one yourself here, for example while a run looks stuck. Download it and send it to whoever looks after OpenProteo. Taking one lasts about ten seconds and changes nothing.
